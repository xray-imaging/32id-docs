========
Micro-CT
========

The 32-ID-C Micro-CT station: a Teledyne Photometrics Kinetix camera on an
Optique Peter detection system, with an Aerotech air-bearing rotary stage,
running fly scans through
`tomoScan <https://tomoscan.readthedocs.io>`_.
